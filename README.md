FlowOps adalah aplikasi web berbasis cloud yang membantu seller online mendeteksi, memprioritaskan, dan menangani pesanan bermasalah sebelum melewati tenggat pemrosesan.

## Pengembangan

Backend FlowOps ditulis dengan **TypeScript** dan Express.

```bash
npm install
npm run dev
```

Perintah yang tersedia:

- `npm run dev` menjalankan server TypeScript dengan reload otomatis.
- `npm run build` mengompilasi `src/` ke `dist/`.
- `npm start` menjalankan hasil kompilasi.
- `npm test` menjalankan pengujian API.
- `npm run typecheck` memeriksa tipe tanpa membuat berkas hasil kompilasi.
