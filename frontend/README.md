# Frontend FlowOps

Direktori ini disiapkan untuk aplikasi web FlowOps. Belum ada aplikasi frontend yang dapat dijalankan; implementasi layar akan mengikuti [rancangan Stitch](../docs/desain-stitch.md) dan [PRD](../docs/prd.md).

Rancangan saat ini meliputi landing page, login, dashboard, antrean exception, detail order, impor CSV, dan pengaturan. Saat mulai membangun, hubungkan layar ke endpoint yang benar-benar tersedia dalam [referensi API](../docs/api.md). Fitur yang API-nya belum tersedia perlu ditandai sebagai demo.
